# Bitácora de sesión

- **Fecha:** 2026-11-20
- **Objetivo:** Documentar el veredicto humano del experimento 1 (`hero-cinetico`) y crear el experimento 2 (`modelo-3d`) con 3D declarativo nativo (`<model-viewer>`).
- **Proceso:** Se leyeron `ESCALA.md`, `AGENTS.md`, `BITACORA.md` y `README.md`. Se verificó la disponibilidad de las URLs públicas usadas por el experimento 2 (CDN de `model-viewer` y `Astronaut.glb`) con respuestas HTTP 200 y tipos esperados, sin descargar el modelo. Se creó `proyectos/hero-cinetico/VEREDICTO.md` con el feedback humano literal y la conclusión técnica indicada. Se creó `proyectos/modelo-3d/` con `index.html` (módulo CDN, `<model-viewer>` configurado con `camera-controls`, `auto-rotate`, `shadow-intensity="1"`, `environment-image="neutral"` y `alt` descriptivo), `styles.css` y `README.md`. Se cerró `hero-cinetico` en la bitácora con su veredicto y se abrió `modelo-3d` con nivel esperado `P:1, O:2, I:2, D:2 → global:2`. Se actualizó el README raíz.
- **Errores y Correcciones:** No hubo errores de código. Las quejas de navegador (Safari u otros) sobre carga de CDN/modelo no pudieron evaluarse de forma interactiva en este entorno; se anotó la disponibilidad de recursos (HTTP 200) y se dejó la validación de quejas en navegador como pendiente para el humano.
- **Decisiones de Diseño:** Se respetó el feedback humano literal en el veredicto. La etiqueta real de `hero-cinetico` se mantuvo en `D:3` (técnicas usadas) pese a la percepción de volumen dudosa, aclarada como ejecución débil. Para `modelo-3d` se usó el CDN oficial de Google como `<script type="module">`, sin npm ni copia local del GLB, con foco visible en el visor.
- **Iteraciones:** 1 (una pasada de creación y documentación). No se instalaron dependencias ni se hicieron push/remotos.
