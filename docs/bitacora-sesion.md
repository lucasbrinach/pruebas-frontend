# Bitácora de sesión

- **Fecha:** 2026-11-20
- **Objetivo:** Crear el Experimento 3 (`scroll-3d-astronaut`) con parallax inverso, astronauta 3D y astros SVG/CSS.
- **Proceso:** Se leyeron `ESCALA.md`, `AGENTS.md`, `BITACORA.md` y `README.md`; se registró el nivel esperado antes de crear archivos. Se implementó `proyectos/scroll-3d-astronaut/` con: `index.html` (contenedor `430vh`, escena sticky, `<model-viewer>` con `Astronaut.glb`, capas SVG/CSS de Saturno, asteroide con marciano, planeta del Principito y aves, y títulos "El viaje"/"El Principito"), `styles.css` (fondo estrellado, posicionamiento y estilos) y `app.js` (un único `rAF`, lectura pasiva de scroll, `translate3d` para bajar astronauta y subir astros a distintas velocidades, y respeto de `prefers-reduced-motion`). Se creó el README del experimento y se actualizaron README raíz y bitácora general.
- **Errores y Correcciones:** No hubo errores de código. `node --check` pasó y los archivos se sirvieron correctamente vía HTTP local. No se realizó verificación visual interactiva en navegador real dentro de este entorno; quedó anotada como pendiente.
- **Decisiones de Diseño:** Nivel esperado/real declarado `P:3, O:3, I:2, D:3 → global:3`. Se usó `<model-viewer>` desde CDN y GLB público (sin descargas ni npm), con controles de cámara y auto-rotación. El astronauta baja hasta ~80vh y las capas de astros suben con factores distintos para reforzar la profundidad.
- **Iteraciones:** 1 (implementación y verificación local). No se instalaron dependencias ni se hicieron push/remotos.
