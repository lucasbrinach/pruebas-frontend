# Bitácora de sesión

- **Fecha:** 2026-11-20
- **Objetivo:** Crear el primer experimento del repo, `hero-cinetico`, con nivel esperado `P:3, O:3, I:3, D:3 → global:3`, y registrar su cierre en la bitácora general.
- **Proceso:** Se leyeron `ESCALA.md`, `AGENTS.md` y `BITACORA.md` antes de empezar; la etiqueta esperada se anotó en la bitácora previo a escribir código. Se crearon `index.html` (hero de 100dvh, cuatro capas, SVG inline, CTA, salida de FPS), `styles.css` (perspective, preserve-3d, translateZ, keyframes, reduced-motion, is-paused) y `app.js` (un único rAF, scroll pasivo, lerp de puntero, deviceorientation con permiso en iOS, IntersectionObserver y visibilitychange). Se añadió el README del experimento. Verificación: `node --check`, servidor local con HTTP 200 para los cuatro archivos, arnés de DOM simulado que confirmó transforms al hacer scroll y mover el cursor, pausa y modo reducido, y apertura en Chrome headless sin errores de JavaScript de la página. Se actualizaron `README.md`, `BITACORA.md` y esta bitácora.
- **Errores y Correcciones:** No hubo errores de código. Chrome headless mostró errores GPU/CVDisplayLink propios del entorno, no de la página; no se interpretaron como fallos del experimento. No se logró una medición de FPS fiable en headless, por lo que se dejó un contador en pantalla y se anotó la limitación en `BITACORA.md`.
- **Decisiones de Diseño:** Cuatro capas con velocidades 0.08/0.22/0.45/0.8 y profundidades -180/-90/30/110 px; tilt máximo de ±6°; `touch-action: pan-y` para no bloquear el scroll; CTA funcional que desplaza a la siguiente sección. Nivel real reportado: `P:3, O:3, I:3, D:3 → global:3`.
- **Iteraciones:** 1 (una pasada de implementación más una ronda de verificación local).
